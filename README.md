## 🏗️ Architecture Overview

### Three Core Components

**1. Small Models (Eigenstates)**
- Narrow scope, deep expertise
- 12M-350M parameters (not billions)
- Low hallucination, high signal
- Each model knows its limits

**2. Tensor RAG (Multi-Dimensional Evidence)**
- Traditional RAG: Flat vector similarity
- Tensor RAG: Time × Source × Confidence × Modality × Jurisdiction
- Preserves context, not just content
- Patent-pending innovation

**3. Uncertainty Quantification**
- Confidence from evidence agreement (not model internals)
- Explicit deferral when confidence < threshold
- Contradictions preserved, not synthesized away
